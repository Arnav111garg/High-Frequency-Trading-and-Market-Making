# High-Frequency Trading & Market Making Framework

A comprehensive Python implementation of quantitative models, signals, and execution algorithms used in High-Frequency Trading (HFT) and Electronic Market Making.

This repository bridges the gap between theoretical market microstructure and practical code, covering everything from limit order book dynamics and order flow imbalance to state-dependent inventory management, optimal execution, and exchange-level matching simulations.
